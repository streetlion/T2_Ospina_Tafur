## Descripcion

Repositorio del proyecto Maven desarrollado para la Evaluacion 02 del curso de
Lenguaje de Programacion II. Su finalidad es evidenciar la preparacion,
configuracion y linea base del repositorio: exclusiones mediante `.gitignore`,
historial ordenado con commits trazables y verificacion del estado del proyecto.

## Estructura

- `pom.xml` - configuracion del proyecto Maven.
- `.gitignore` - exclusiones de archivos que no deben versionarse.
- `src/main/java` - codigo fuente del proyecto.
- `src/main/resources` - recursos del proyecto.
- `src/test/java` - pruebas del proyecto.
